# Support

Use [GitHub Discussions](https://github.com/stuttter/wp-datepicker-styling/discussions)
for usage questions. Use the GitHub issue tracker for reproducible defects and
narrowly scoped enhancements.

Report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/stuttter/wp-datepicker-styling/security/advisories/new),
not in a public issue.
